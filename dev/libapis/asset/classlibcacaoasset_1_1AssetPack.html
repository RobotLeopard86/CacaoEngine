static AssetPack OpenFromFile(const std::string &filePath)

Open an asset pack file from on disk.

Parameters:

filePath – The relative path (from the working directory) to the file to open

Throws:

  • std::runtime_error – If the file does not exist or is not an asset pack

  • std::runtime_error – If the pack is of an incompatible revision

  • std::runtime_error – If decoding fails

Returns:

The opened pack

static AssetPack OpenFromStream(std::istream *stream)

Open an asset pack file from an input stream.

Warning

The new asset pack will control the stream exclusively, and it is not recoverable from the object. Do not perform further operations on the stream after calling this!

Parameters:

stream – The stream from which to load the pack

Throws:

  • std::runtime_error – If the stream pointer is invalid

  • std::runtime_error – If the stream is not an asset pack

  • std::runtime_error – If decoding fails

Returns:

The opened pack
